# Desk-Mate App 设计文档

> 桌面编程辅助助手 — 一个带触摸屏、BLE+WiFi 的桌面伴侣

---

## 1. 硬件约束回顾

- **主控**: ESP32-C6 (WiFi 6 + BLE 5)
- **屏幕**: 2.16 寸 AMOLED 480×480 触摸屏 (WaveShare)
- **内存**: 512KB SRAM (无 PSRAM)
- **分区**: 4MB 默认分区 (APP 区 ~1.2MB)
- **空间**: 当前固件（表情 + WiFi）~1.2MB，99% 已用
- **供电**: 板载锂电池

### 关键约束

- LVGL 全屏 buffer (480×480×2) = 460KB → **无法分配**
- BLE 与 WiFi 可共存但内存紧张
- 需要为 LVGL、BLE stack、WiFi stack 各预留内存
- APP 区 1.2MB 限制 → 需要用 8MB 分区表（有卡死风险，需测试）

## 2. 功能需求总览

| # | 功能 | 交互方式 | 数据流 | 优先级 |
|---|------|---------|--------|--------|
| 1 | 蓝牙设备管理 | 界面列表 + 扫描/连接/断开 | BLE ↔ PC | P0 |
| 2 | LLM Token Plan 额度 | 定时拉取 + 显示 | BLE ↔ PC ↔ LLM API | P0 |
| 3 | Agent ACP 确认/取消 | 弹出确认卡 + 按钮 | BLE ↔ PC ↔ Agent | P0 |
| 4 | 按住说话录音 → 语音转文字 | 按住→录音→BLE发送→PC转文字 | BLE → PC → ASR服务 | P1 |
| 5 | 番茄钟 | 设置/启动/暂停/完成 | 纯本地 | P1 |
| 6 | 桌宠交互 | 点击、双击、长按 → 打趣的话 | 本地播放 + BLE 同步 | P1 |
| 7 | 扁平滑屏导航（Apple Watch 式） | 左右滑动切换页面 | 纯本地 UI | P0 |

## 5. 通信协议

### 5.1 BLE 数据通道

```
DeskMate 设备 (Peripheral)
    │
    ├── BLE GATT Service: "DeskMate"
    │   ├── Characteristic: "command" (write)      ← PC → DeskMate
    │   ├── Characteristic: "data" (notify)         ← DeskMate → PC
    │   ├── Characteristic: "audio" (notify)        ← 音频流
    │   └── Characteristic: "status" (read/notify)  ← 状态同步
    │
    └── PC 端 (Central)
        └── 配套程序 "desk-mate-daemon"
            ├── BLE Manager
            ├── LLM API 额度查询
            ├── ACP 协议对接
            ├── 语音转文字 (Whisper)
            └── 系统通知转发
```

### 5.2 命令协议 (JSON over BLE)

```json
// PC → DeskMate (command)
{
  "cmd": "token_update",
  "data": {
    "used": 1234567,
    "remaining": 823456,
    "total": 2058023,
    "models": {"v4": 40, "v4p": 20, "gpt": 40}
  }
}

{
  "cmd": "acp_request",
  "data": {
    "id": "req_001",
    "title": "发送邮件",
    "description": "确认发送邮件给张三？",
    "detail": "主题: 项目进度汇报\n收件人: zhangsan@example.com"
  }
}

{
  "cmd": "stt_result",
  "data": {
    "text": "帮我写一个Python爬虫",
    "confidence": 0.95
  }
}

{
  "cmd": "pet_say",
  "data": {
    "text": "代码写完了记得测试啊 😎"
  }
}

// DeskMate → PC (data)
{
  "type": "acp_response",
  "data": {
    "id": "req_001",
    "action": "confirm"  // 或 "cancel"
  }
}

{
  "type": "token_request",
  "data": {}
}

{
  "type": "audio_data",
  "data": {
    "format": "pcm_s16le",
    "sample_rate": 16000,
    "chunks": [...]  // base64 编码音频片段
  }
}
```

### 5.3 音频数据流

- 采样率: 16kHz
- 格式: 16-bit PCM S16LE
- 分片: 每 100ms 音频数据为一片（3200 bytes/片）
- BLE MTU 协商后分片发送

## 6. 内存规划

```
ESP32-C6 512KB SRAM 分配预估:

┌─────────────────────────────┐
│  RTOS 内核 + 栈      ~40KB   │
├─────────────────────────────┤
│  WiFi Stack           ~80KB  │  ← 休眠时可释放
├─────────────────────────────┤
│  BLE Stack (NimBLE)  ~80KB  │
├─────────────────────────────┤
│  LVGL core + fonts   ~60KB  │
├─────────────────────────────┤
│  LVGL draw buffer     ~48KB  │  ← 50行 × 480px × 2bytes
├─────────────────────────────┤
│  HTTP 缓存/JSON       ~30KB  │
├─────────────────────────────┤
│  Audio buffer          ~8KB  │  ← 100ms PCM 数据
├─────────────────────────────┤
│  BLE GATT buffer      ~20KB  │
├─────────────────────────────┤
│  剩余 (heap)          ~146KB │
└─────────────────────────────┘

总计:                    ~512KB
```

**关键**: 剩余 heap 约 146KB，够用但紧张。WiFi 休眠时可释放 ~80KB。

## 12. 与 PC 端的配套程序

PC 端需要一个后台守护程序 `desk-mate-daemon`：

```
desk-mate-daemon/
├── main.py                  # 入口，BLE 中心设备
├── ble/
│   ├── manager.py           # BLE 连接管理
│   └── protocol.py          # 协议解析/组装
├── llm/
│   └── token_monitor.py     # LLM Token plan 查询
├── agent/
│   └── acp_handler.py       # ACP 协议对接
├── asr/
│   └── whisper_client.py    # 语音转文字
└── cli/
    └── main.py              # 命令行界面
```

**功能**:
1. BLE Central 端，自动发现和连接 DeskMate 设备
2. 定时查询 LLM Token plan 额度 → 通过 BLE 同步
3. 监听 Agent 的 ACP 请求 → 转发到 DeskMate
4. 接收音频 → 调用 ASR（Whisper）→ 返回转写结果
5. 推送桌宠打趣话到 DeskMate
6. 可选：转发系统通知

## 14. 设计决策记录

| 决策 | 选项 | 选择 | 理由 |
|------|------|------|------|
| BLE 角色 | Central / Peripheral | Peripheral | ESP32 作为外设，PC 作为中心，不必在嵌入式端维护连接表 |
| BLE 栈 | ESP-BLE / NimBLE | NimBLE | ESP32-C6 官方推荐 NimBLE，内存占用更小 |
| 导航方式 | LVGL 页面 / 自定义 | LVGL `lv_page` + scroll | 复用 LVGL 的滚动机制，自定义动画 |
| 语音编码 | ADPCM / PCM | PCM S16LE 16kHz | Whisper 原生支持，不需要转码 |
| 打趣话存储 | 硬编码 / BLE 推送 | BLE 推送 | 不占用固件空间，PC 端可随时更新内容 |
| 分区表 | 4MB / 8MB | 先测试 8MB | 当前 4MB 空间已满，必须升级 |
| 状态栏 | LVGL 原生 / 自定义 | 自定义 | 统一管理与各页面协调 |
