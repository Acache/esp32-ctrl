# log/ — 开发日志 & 经验沉淀

本目录是整个项目最重要的知识管理区。

## 文件命名约定

- `YYYY-MM-DD.md` — 每日开发日志：做了什么、遇到什么问题、怎么解决的
- `fix-XXXX.md` — 特定问题的详细修复记录
- `learnings.md` — 积累的经验、坑、最佳实践
- `troubleshooting.md` — 常见问题和诊断步骤

## 日志格式建议

每篇日志包含：
1. **日期**
2. **做了什么**
3. **遇到的问题 & 原因**
4. **解决方案 & 关键代码**
5. **遗留事项/下一步**

记住：今天记下的坑，是明天的捷径。
