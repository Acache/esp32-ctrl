## 技术细节备忘

### LVGL v8 颜色格式
```
lv_color_t = uint16_t (2 bytes)
  bit layout: RRRRRGGGGGGBBBBB (RGB565)
  大端字节序: [R_high][G_low+B_high] (如 0x18c5)
  小端字节序: [G_low+B_high][R_high] (如 0xc518)

LV_COLOR_DEPTH = 16
LV_COLOR_16_SWAP = 0 (默认)

lv_color_hex(0x1A1A2E) 实际是:
  RGB(26, 26, 46) = RGB565 0x18a5
  内存中 uint16_t = 0x18a5

#4ECAF5 = RGB(78, 202, 245) = RGB565 0x9b66
```

### macOS screencapture 用法
```bash
# 截取指定窗口 ID（需要先获取）
screencapture -x -w -l <window_id> /tmp/output.png

# 全屏截图
screencapture -x /tmp/output.png

# 从剪贴板获取截图
screencapture -x - > /tmp/output.png
```
