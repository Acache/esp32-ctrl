## 硬件

- **ESP32-C6-Touch-AMOLED-2.16** — [官方文档](https://docs.waveshare.net/ESP32-C6-Touch-AMOLED-2.16/)
- ESP32-C6 模组规格：RISC-V 单核 160MHz, 512KB SRAM, 16MB Flash
- 屏幕驱动：CO5300 (QSPI) + CST9220 触控 (I2C)
- IMU：QMI8658 (六轴)
- RTC：PCF85063
- 音频：ES8311 编解码 + ES7210 ADC (回声消除)
- 电源管理：AXP2101
